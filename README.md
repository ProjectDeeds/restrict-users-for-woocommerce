# Restrict Users for WooCommerce

A WordPress plugin that restricts selected WooCommerce customers from completing checkout while allowing browsing and cart use.

Administrators can manage restricted user IDs, enable or pause restrictions, and customize customer notices under **WooCommerce → Restrict Users**.

## Requirements

- WordPress 6.5 or later
- PHP 7.4 or later
- WooCommerce installed and active

## Installation

1. Place this repository's contents in `wp-content/plugins/restrict-users-for-woocommerce/`.
2. Activate **Restrict Users for WooCommerce** in the WordPress Plugins screen.
3. Open **WooCommerce → Restrict Users** to configure restrictions.

See [readme.txt](readme.txt) for WordPress plugin metadata and the changelog.

## Repository scope

This repository contains only this plugin. The surrounding WordPress installation, database, configuration, uploads, themes, and other plugins are outside its Git root.
